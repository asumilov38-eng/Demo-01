# YVL STORE — demo

Демонстрационная версия интернет-магазина YVL STORE. Это статический frontend: backend, база данных и регистрация покупателей не требуются.

## Локальный запуск

Требуется Node.js 20 или 22.

```bash
npm install
npm run dev
```

Откройте адрес Vite, обычно `http://localhost:5173`.

## Сборка

```bash
npm run build
npm run preview
```

## Публикация на GitHub Pages

1. Создайте публичный репозиторий `Demo-01`.
2. Загрузите содержимое этой папки в корень репозитория, без `node_modules` и `dist`.
3. В GitHub откройте **Settings → Pages** и выберите **GitHub Actions** в разделе Build and deployment.
4. Отправьте изменения в `main`; workflow `Deploy YVL STORE demo to GitHub Pages` соберёт и опубликует сайт.
5. Ссылка будет иметь вид `https://asumilov38-eng.github.io/Demo-01/`.

Маршрутизация работает через HashRouter, поэтому переходы и страницы товаров корректно открываются на GitHub Pages.

## Что работает в демо

- Главная страница и промо-баннер.
- Каталог, поиск, фильтрация и сортировка.
- Страницы товаров.
- Избранное в `localStorage` браузера.
- Одинаковая нижняя навигация из четырёх вкладок на ПК и смартфонах.
- Адаптивная верстка и анимации.

Товары, цены, описания, фотографии и ссылки — демонстрационные. Серверные функции и админ-панель в этой статической демо-сборке не используются. Перед коммерческим запуском замените примеры на данные заказчика и подключите backend.
